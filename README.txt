# Kyle Reinne S. Diala — Executive VA Portfolio

This is a static website portfolio for an entry-level Executive Virtual Assistant / BSIT student.

## Files
- index.html — main website
- styles.css — design and responsive layout
- script.js — mobile menu and scroll animations
- assets/ — profile image and six Excel work samples

## How to publish
Upload the entire folder to a static hosting service such as GitHub Pages, Netlify, or Vercel. Keep the `assets` folder in the same directory as `index.html`.

All six projects are clearly labeled as fictional practice projects and should not be presented as paid client work.
